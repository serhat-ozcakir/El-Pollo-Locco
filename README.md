# 🕹️ El Pollo Loco – Jump & Run Game

## 🚀 Overview

El Pollo Loco is a browser-based jump and run game developed using JavaScript (OOP).  
The player controls a character, fights enemies, collects items, and defeats a final boss.

The project focuses on object-oriented programming, game logic, animations, and user interaction.

---

## 🎮 Features

- 🧍 Playable animated character with smooth movement and jump mechanics  
- 👾 Multiple enemy types with different behaviors  
- 🐔 Final boss fight with attack mechanics  
- 🪙 Collectable items (coins, bottles) with score tracking  
- ❤️ Health and status bar system  
- 🔊 Sound effects and background music with mute functionality  
- 🔁 Game over & restart functionality  
- 📱 Responsive design with mobile support  

---

## 🛠️ Tech Stack

- JavaScript (Object-Oriented Programming)
- HTML5
- CSS3
- Bootstrap

---

## 🧠 Key Concepts

- Object-Oriented Programming (classes, inheritance, encapsulation)
- Game loop & animation handling
- Collision detection
- Event handling & user input
- State management (health, score, game status)
- DOM manipulation and rendering logic

---

## 🎯 Gameplay

- Start the game via the start button  
- Navigate through the level and avoid or defeat enemies  
- Collect coins and items to increase score  
- Fight the end boss using collected resources  
- Win or lose → restart or exit the game
